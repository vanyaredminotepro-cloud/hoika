# Warlord RP Bot

Telegram-бот для военно-политического РП-проекта **Warlord RP**.

## Архитектура

Два связанных ИИ-модуля в одном боте:

- **Модуль А — Ассистент**: отвечает игрокам по правилам, механике, карточкам. Read-only доступ к БД.
- **Модуль Б — Механик**: планировщик, обновляет карточки стран/группировок каждые 2 часа, публикует/редактирует сообщения.

## Возможности

- ✅ Только DeepSeek и Groq провайдеры (переключение через конфиг)
- ✅ Жёсткая защита от джейлбрейков и оффтопа
- ✅ Экономия токенов: кэширование, FAST/FULL модели, лимит истории
- ✅ Карточки формируются из БД, LLM только извлекает события
- ✅ Валидация карточек: защита от бреда (население, армия, бюджет, постройки)
- ✅ Анрег/заморозка/АФК статусы
- ✅ Вопросы админу ОДИН РАЗ с запоминанием
- ✅ SQLite база с полной схемой
- ✅ Логирование, security log, token report

## Установка

```bash
cd warlord_bot
pip install -r requirements.txt
cp .env.example .env
# Заполните .env своими значениями
python main.py
```

## Команды

| Команда | Описание |
|---------|----------|
| `/start`, `/help` | Справка |
| `/ai <вопрос>` | Спросить ассистента |
| `/status` | Статус бота (админ) |
| `/tokenreport` | Отчёт по токенам (админ) |
| `/process` | Запустить цикл вручную (админ) |
| `/cards` | Переопубликовать карточки (админ) |
| `/newcountry <type> <JSON>` | Создать страну/группировку (админ) |
| `/unreg <name>` | Анрег страны (админ) |
| `/mute <user_id> [hours]` | Мьют пользователя (админ) |
| `/unmute <user_id>` | Размьют (админ) |
| `/security` | Лог безопасности (админ) |

## Структура БД

- `countries` — карточки стран
- `factions` — группировки
- `country_factions` — связи
- `persons` — личности
- `topics` — топики форума
- `known_entities` — известные сущности
- `pending_news` — новости к обработке
- `questions_log` — вопросы админу
- `security_log` — попытки взлома/оффтоп
- `changes_log` — история изменений карточек
- `meta` — служебные данные

## Правила валидации (защита от бреда)

- Население ≥ 60 для активных стран
- Армия ≤ 30% населения, рост только при посте о мобилизации
- Бюджет: рост без источника — откат
- Постройки: только по постам, с таймерами
- Стабильность/поддержка/счастье в диапазоне 0-100
- Анрег = обнуление показателей
