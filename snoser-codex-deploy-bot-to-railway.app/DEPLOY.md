# Деплой WARLORD RP на Railway

## Обзор

Проект состоит из двух сервисов, которые деплоятся на Railway:

1. **Bot** — основной бот Telegram (`python -m app.warlord.main`)
2. **Web** — веб-редактор статистики с аутентификацией (`python -m app.webapp"`)

Оба сервиса используют одну и ту же SQLite базу данных (`warlord_data/warlord.sqlite3`).

## Файлы конфигурации

| Файл | Назначение |
|------|------------|
| `Dockerfile` | Образ с Python 3.11 и всеми зависимостями |
| `railway.toml` | Конфигурация Railway: два сервиса (bot + web) |
| `Procfile` | Альтернативный формат для Heroku-подобных платформ |
| `requirements.txt` | Python зависимости (включая Flask) |
| `.env.example` | Пример переменных окружения |

## Как Deploy'ить

### Способ 1: Через Railway Dashboard (рекомендуется)

1. Загрузите код в GitHub репозиторий
2. Подключите репозиторий к Railway
3. Railway автоматически обнаружит `railway.toml` и создаст два сервиса: `bot` и `web`
4. Добавьте переменные окружения в настройках каждого сервиса
5. Для сервиса `web` добавьте persistent Volume на `/app/warlord_data` (чтобы база данных не терялась при перезапуске)
6. После деплоя скопируйте URL сервиса `web` (например, `https://warlord-web-xxx.railway.app`)
7. Установите эту же URL в переменную `WEB_APP_URL` для сервиса `bot`
8. Перезапустите бота

### Способ 2: Через Railway CLI

```bash
# Войти в Railway
railway login

# Инициализировать проект
railway init

# Запушить код
railway up

# Открыть dashboard
railway open
```

## Настройка Telegram Web App (Mini App)

После деплоя обоих сервисов:

1. Откройте @BotFather в Telegram
2. Выберите своего бота → «Bot Settings» → «Web App»
3. Введите URL веб-приложения: `https://ваш-веб-сервис.railway.app`
4. Сохраните

После этого в боте появится команда `/webapp`, которая открывает веб-редактор стран прямо внутри Telegram.

## Доступ к веб-редактору

После деплоя веб-приложение доступно по URL вашего сервиса `web`:

- **Вход**: `/login` — введите пароль из `WARLORD_ADMIN_PASSWORD`
- **Список стран**: `/` — таблица со всеми странами, поиск, фильтры, сортировка
- **Карточка страны**: `/country/<имя>` — полная статистика
- **Редактирование**: `/country/<имя>/edit` — форма для изменения любого поля
- **API**: `/api/countries`, `/api/country/<имя>`, `/api/stats`

## Как работают правки из веба (внутри Telegram)

1. В боте нажмите `/webapp` → кнопка «🌐 Открыть веб-редактор стран»
2. Веб-приложение открывается внутри Telegram (Mini App)
3. Выберите страну → отредактируйте любое поле → нажмите «Сохранить»
4. Данные отправляются боту через `Telegram.WebApp.sendData()`
5. Бот сохраняет изменения в БД с блокировкой ⭐ (защита от перезаписи экономическим циклом)
6. Изменения появляются в карточке страны в следующем цикле обновления

## Безопасность

- Веб-редактор защищён паролем (`WARLORD_ADMIN_PASSWORD`)
- Сессии хранятся в зашифрованных куки (`FLASK_SECRET_KEY`)
- Все маршруты кроме `/login`, `/logout`, `/static/*` требуют авторизации
- Изменения через веб защищены блокировками (⭐), чтобы цикл экономики не стёр их
- Web App работает только по HTTPS (требование Telegram)
